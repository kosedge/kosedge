# Desk handicaps 2026

Bylined multi-sport handicaps for `/pro/desk` and `/pro/desk/[slug]`.

## Publish a piece

1. Drop a new `.md` file in this folder. The filename (without `.md`) is the URL slug.
2. Use the locked chrome from `docs/writers/output-formatting.md`: `#` title, `**By …**` byline, `**Sport:**`, `**Category:** Desk handicap`, `**Angle:**`, `**Date:**` / `**Timestamp:**`, market lines, `**Sources:**`, body prose, one or more `**Handicapper’s Note**` blocks, disclaimer.
3. Do not strip or rewrite writer voice. Fair numbers that say research-adjusted stay research-adjusted — do not invent a Kos Edge model print.
4. Rematerialize is automatic: the web loader walks this directory on each request. Update `project-log.md` after delivery.
