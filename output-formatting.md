# Output Formatting Standards
Required Structure
1. Clear title
2. Short lede that states the market question or key number
3. Body analysis
4. Handicapper’s Note (mandatory for market pieces; for pure news breaks use N/A / Pass when no number)
Handicapper’s Note Template
**Handicapper’s Note**  
Fair number: [X]  
Market number: [Y]  
Lean: [Over / Under / Side / Pass]  
Confidence: [1–5]  
Key risk: [one sentence]
Required Disclaimer (append to every piece)
“This analysis is for informational and educational purposes only. Sports betting involves risk. Please bet responsibly. Past performance does not guarantee future results. Kos Edge Analytics is not responsible for any financial losses.”

## News-break / camp notebook (training camp)

When speed matters (see `docs/writers/TRAINING_CAMP_DESK.md` and `research-standards.md`):

1. Title with team + what broke
2. **Timestamp** (date/time + timezone)
3. **Sources** — outlet URLs and/or writer `@handles` (never invent)
4. Short lede + 2–4 bullets
5. Handicapper’s Note if a market is involved (else N/A / Pass)
6. Required disclaimer

Prefer news-break length (120–280 words) over essay form for breaking camp items.
