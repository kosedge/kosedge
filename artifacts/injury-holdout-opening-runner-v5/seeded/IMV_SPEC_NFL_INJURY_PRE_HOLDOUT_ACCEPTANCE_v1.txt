(b) SCORER UNIT TESTS - synthetic fixtures, known answers, all must pass (one failure = FAIL)
==========================================================================================
Fixtures are Cursor-built, deposited with shas and the expected answers written BEFORE the run.
 T-1 Paired CLV sign: 3 games, close spread -3.0; base -3.0, adj -4.5 (home fav, adj moves toward close
     direction of later market?) Rule fixed: CLV_pts(arm) = signed points the arm's pick beats the close;
     fixture where adj beats close by 1.5 and base by 0 => delta = +1.5 exactly; mirrored fixture => -1.5.
     Implied-prob CLV computed both arms; delta sign must match points sign.
 T-2 Holm direction: p = [0.001,0.01,0.02,0.03,0.04,0.2,0.3,0.5,0.9] -> step-down at 0.05/9..: reject only
     p=0.001 (0.001<=0.00556; 0.01>0.00625 stops). Primary set to p=0.001 => "significant". A rejection
     must be reported as SIGNIFICANT; any code mapping rejection -> FAIL = test FAIL.
 T-3 Week-block bootstrap: fixed seed = 20261023 (PRE-REGISTERED NOW; numpy default_rng(20261023)), 10,000
     resamples, resampling whole weeks with replacement, paired (same weeks both arms). Fixture: 10 weeks,
     constant delta 0.01 per game => CI exactly [0.01,0.01]. Second fixture: deposit result, re-run must be
     bit-identical; seed None or unseeded = FAIL. Bootstrapping games instead of weeks = FAIL (fixture
     with within-week correlation where game-level CI is visibly narrower must show the week CI).
 T-4 Brier/LL/reliability: p=[0.8,0.6,0.3], y=[1,0,0]: Brier=(0.04+0.36+0.09)/3=0.163333..; LL=
     -(ln0.8+ln0.4+ln0.7)/3=0.498434 (nats, tol 1e-6). Reliability: 10 equal-width bins with counts
     (bins 3,6,8 count 1). Calibration slope on a fixture generated from p (perfect) -> 1 within tol set
     in fixture; p clipped to [1e-15,1-1e-15] and clip count reported.
 T-5 Phi formula: P(home cover) = Phi((pred_margin - line_margin)/sigma), win = Phi(pred_margin/sigma) with
     the UNSHRUNK sigma from the frozen fit_object (6a5490db); fixture pred 3, line 0, sigma 13 =>
     Phi(0.230769)=0.591253 (tol 1e-6). Any shrink/rescale of sigma = FAIL. (Design condition T-*, not K-2/K-3.)
 T-6 I-2 count: 2 synthetic FULL seasons (272 REG games each) with delta_margin != 0 on exactly 251 + 250
     = 501 games, and edge_base != 0 on all 544 => count = 501 (PASS n). Variant with 499 => INCONCLUSIVE.
     Variant with 501 games but 1 season + partial => INCONCLUSIVE. Counting edge != 0 = FAIL.
 T-7 Missing-close exclusion: 10 games, close missing on 2 BEFORE scoring => both arms scored on the same
     8 game_ids; report n_missing_close=2 (per season), n_identical=8, n_edge0 per arm. Any arm-specific
     drop by edge or result, or different id sets = FAIL.
 T-8 NULL never zero: components with NULL (each input removed in turn, a156459b P-3) => adj NULL + flag,
     game excluded from the adjusted arm AND counted; any 0.0 substitution = FAIL (silent zero substitution).
 T-9 Planted leak: fixture with one injury row source_ts > as_of_ts and one closing/outcome value joined
     before freeze => scorer must detect, mark LEAKAGE, and fail the run (a156459b P-2b). Not detected = FAIL.
 T-10 Reversed gate: fixture where primary is Holm-significant, CI > 0, K-4 PASS => must return VALUE PROVEN;
     a second where CI includes 0 => NO CLAIM; a third with K-4 LL UCI = 0.0021 => layer off/NO CLAIM. A
     scorer that returns FAIL on rejection, or PASS when K-4 fails, or reads thresholds other than the
     quoted ones = FAIL. Gate constants must be read from / checked against a156459b text, and the run
     dies if the spec file is absent or its sha != a156459b.
