2. PERMANENT AS-OF LEAKAGE GATE (cross-sport; Ryan t4344u)
==========================================================================================
G-PIT (HARD): No historical model input may contain information whose availability timestamp is
  later than the prediction cutoff for that prediction.
Applies to: injuries, rosters, depth charts, transactions, quarterback changes, odds, weather,
  and every other time-sensitive feature.
NFL-extra (HARD): historical roster-membership and player-role tests MUST cover trades, injuries,
  starter replacements, and practice-squad promotions.
Fail closed: any violation → row BLOCKED or component NULL per existing NULL contract; never
  invent membership/role; never zero-fill a missing PIT field to keep a game eligible.
This gate is permanent and applies beyond the injury layer (NBA/MLB/college reuse).

Definitions (binding for this SPEC):
  prediction_cutoff = the earliest of (kickoff_utc, declared decision_ts) for that game, unless a
    tighter product cutoff is frozen in the revised execution package.
  availability_ts = the earliest time the datum was knowable from the pinned source provenance
    (capture time, publication time, or provider as_of). Ingest/updated_at alone is NEVER enough.
  week-aware roster row = a membership or depth/role assignment tied to (season, week, team,
    player_id) with availability_ts <= prediction_cutoff for every game that uses it.
